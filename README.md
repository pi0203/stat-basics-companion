# 사회과학통계의 기본 · 함께 읽는 교재 (비공식)

김수영 『사회과학통계의 기본』(학지사, 2019)을 **처음 배우는 사회과학(특히 심리학) 전공자**가 책 옆에 펴 두고 쓰는 비공식 동반 교재입니다. 컴퓨터와 통계가 낯선 사람을 먼저 생각하고 만들었습니다.

- **책 본문과 그림은 싣지 않습니다.** 쪽수만 가리킵니다. 책은 직접 구해 읽어 주세요.
- 로그인, 서버, 방문 통계, 바깥으로 보내는 요청이 없습니다. 기록은 각자 브라우저에만 남고, 파일로 내보낼 수 있습니다.
- 설명·비유·위젯은 조은찬이 AI(Claude)와 함께 만들었고 **틀릴 수 있습니다(작성자 확인 전)**. 틀린 곳은 Issues로 알려 주세요.

## 쓰는 법
1. `index.html`을 두 번 눌러 브라우저에서 엽니다. (또는 공개 주소)
2. 처음 쪽 「교재 뼈대」에서 20장을 훑으며 장마다 「이 장은 ___를 하는 장」 한 줄을 적습니다 (1바퀴).
3. 「이 장 열기 →」가 있는 장은 한 줄씩 읽는 칸이 있습니다 (2바퀴). 지금은 2장(R의 기초)만 있습니다.

### 네 바퀴
| 바퀴 | 묻는 것 |
|-|-|
| 1. 지도 그리기 | 이 장은 무엇을 하려는 장인가 |
| 2. 한 줄씩 | 이 문장은 무슨 뜻인가 |
| 3. 손으로 | 내 R에서도 책과 같은 결과가 나오나 |
| 4. 써먹기 | 언제 이 분석을 고르고, 결과를 어떻게 쓰나 |

## 장을 더하려면
`docs/FORMAT.md`를 보세요. 장마다 내용 파일(`content/chNN.js`) 하나와, 필요하면 위젯 파일(`widgets/chNN.js`) 하나를 더하고 `index.html`에 두 줄을 넣으면 됩니다.

## 참고한 것
- 짜임: 시냅스터디(synapstudy.kr) 소단원 구성(용어 → 도입 사례 → 생각해보기 → 본문 → 요약 → 사례 해결 → 확인)을 참고했습니다. 글·그림·코드는 가져오지 않았습니다.
- 근거: 스스로 설명하게 하는 질문(Bisra 외 2018 메타분석), 먼저 떠올리기와 간격 두고 다시 보기(Dunlosky 외 2013), 막힌 곳을 쉽게 알리는 장치(The Carpentries), 혼자 배우는 웹 통계 과목(CMU OLI, Lovett 외 2008).
- 예시 자료: R의 `MASS::survey`, `psych::bfi`, `sleep`, 그리고 책이 쓰는 `MASS::Cars93`.
