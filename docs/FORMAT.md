# 형식: 장 하나를 더하는 법

## 파일
- `content/chNN.js` — 그 장의 내용(글). `window.CONTENT.chN = {...}`
- `widgets/chNN.js` — 그 장의 「직접 만져 보기」를 움직이는 코드(있을 때만). `window.WIDGETS.chN = function(){...}`
- `index.html` 아래쪽에 두 파일의 `<script src>`를 더함. (서버 없이 파일을 두 번 눌러도 열리도록 JSON 대신 .js로 둠)

## 장(content) 칸
| 칸 | 뜻 |
|-|-|
| n, title | 장 번호, 책의 장 제목 |
| kicker, h1, lead | 머리 줄, 큰 제목, 한 줄 소개 |
| about | 「자세히 보기」 안의 글(HTML) |
| osbar | true면 Mac/Windows 고르기 표시 |
| sections | 절(칸) 목록 |

## 절(section) 칸
| 칸 | 뜻 |
|-|-|
| id, nav | 칸 이름, 왼쪽 목록에 보일 글 |
| title, page | 칸 제목, 책 쪽수 줄(HTML) |
| blocks | 아래 블록들을 순서대로 |
| mine | 「내 말로 한 줄」 안내 문구 |

절 끝에는 공통 틀이 「내 말로 한 줄」, 「여기서 막힘」, 「이해했어요」를 자동으로 붙임.

## 블록 종류 (시냅스터디 짜임과의 대응)
| type | 화면 | 하는 일 | 시냅스터디에서 대응 |
|-|-|-|-|
| scene (예정) | 자료 장면 | 심리학 연구자가 자료를 연 순간에서 시작 | 도입 사례 |
| meaning | 파란 줄 「뜻」 | 이름보다 뜻을 먼저 | 본문 |
| analogy | 주황 줄 「비유」 | 익숙한 장면으로 | – |
| think | 생각해 보기 | 내 답 먼저 → 점검 기준 → 스스로 체크 → 해설 | 생각해보기 |
| lab | 직접 만져 보기 | 눌러 보며 결과 보기 | 그림 |
| trap | 점선 상자 | 함정, 2019년 책과 지금 R이 다른 곳 | – |
| osbox | Mac/Windows 상자 | `.os-mac` / `.os-win` 안의 글만 보임 | – |
| predict (예정, 3바퀴) | 돌리기 전 짐작 | 짐작 → 실행 → 비교 | Self-Check 퀴즈 |
| html | 그 밖의 글 | – | – |

## 지킬 것
- 책 본문을 옮기지 않는다. 쪽수와 아주 짧은 인용(따옴표, 쪽수)만.
- 새 설명 문장은 뜻을 먼저, 이름을 뒤에. 컴퓨터가 낯선 사회과학 전공자가 읽는다고 생각한다.
- 흉내 낸 R 출력은 지금 R에서 나오는 모양과 맞춘다. 책과 다르면 trap 블록에 적는다.
- 바깥으로 보내는 요청(글꼴, 분석, 외부 스크립트)을 넣지 않는다.
- 숫자 결과가 실제로 돌려 본 것이 아니면 「아직 안 돌림」이라고 쓴다.
